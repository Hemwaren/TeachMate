# TeachMate

TeachMate is an AI-powered web prototype built to support teachers in managing classroom tasks more efficiently. It was developed in response to the hackathon case study by addressing a key educational challenge: teachers often face heavy workloads, limited time, and difficulty giving personalized support to every student. TeachMate helps solve this by combining lesson planning, quiz generation, student performance tracking, class analytics, and AI-based intervention support in one platform.

## 1. General Description

### Project Intro
TeachMate is designed to help teachers save time, identify struggling students earlier, and make better teaching decisions using AI. The system allows teachers to generate lesson plans and quizzes, monitor student scores, detect weak topics, and receive suggested intervention actions. This directly connects to the case study because it focuses on improving education through digital innovation and practical classroom support.

### SDG
TeachMate mainly supports **SDG 4: Quality Education** by helping teachers deliver better, more inclusive, and more effective learning experiences. It also relates to **SDG 10: Reduced Inequalities** by helping identify at-risk learners early and supporting more personalized intervention.

### Target Users
The main target users are:
- school teachers
- educators managing large or mixed-ability classes
- schools looking for simple AI-assisted teaching support
- teachers in environments with limited time and resources
